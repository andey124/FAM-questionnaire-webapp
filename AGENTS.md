# Projektanweisungen

## Produktpraeferenzen

- Die App bleibt komplett deutschsprachig.
- Der Ton soll semi-wissenschaftlich wirken: trocken, formal und plausibel, aber nicht offensichtlich albern.
- Die Begriffe bleiben: Fotzig, Atzig, Mausig und Cringe.
- Cringe ist eine latente Tiefendimension und wird erst ab einem Pufferwert modellrelevant.
- Unter der Visualisierung soll ein Ergebnissatz stehen.
- Der Fragenkatalog darf vorgeschlagen und spaeter leicht angepasst werden.
- Teilen/Speichern ist vorerst nicht Teil der Version 1.
- Die visuelle Richtung ist pastell/chaotisch und soll praktisch im Browser getestet werden.

## Technische Praeferenzen

- Die App soll kostenlos und einfach hostbar bleiben.
- Primaeres Hosting-Ziel ist GitHub Pages.
- Netcup-Webhosting ohne Node.js/Python-Laufzeit soll als statischer Fallback funktionieren.
- Keine Server-Laufzeit voraussetzen; HTML, CSS und JavaScript muessen statisch auslieferbar sein.
- Abhaengigkeiten nur einfuehren, wenn sie einen klaren Nutzen haben.

## Arbeitsweise

- Ab dem initialen Stand werden Aenderungen in kleinen, atomaren Einheiten umgesetzt.
- Commits sollen jeweils genau eine fachliche oder technische Aenderung beschreiben.
- Vor einem Commit nach Moeglichkeit passende Checks ausfuehren.
- Dokumentation soll mit Codeaenderungen mitgezogen werden, wenn sich Verhalten, Setup oder Produktannahmen aendern.
