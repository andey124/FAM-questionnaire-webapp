Datenschutzhinweis

Lokale Auswertung

Diese Anwendung verarbeitet Antworten, Ergebnisprofil, Itemfeedback und ein optionales Pseudonym ausschließlich im Browser. Es wird kein eigenes Backend kontaktiert und die Anwendung speichert keine IP-Adresse.

Lokale Daten

Das optionale Itemfeedback wird im lokalen Speicher des Browsers abgelegt. Es dient nur zur lokalen Einschätzung, welche Fragen im eigenen Fragenpool später geprüft werden könnten.

Ein optional eingegebenes Pseudonym wird nur zur Erzeugung eines lokalen Ergebnissatzes verwendet. Es wird nicht automatisch gespeichert, veröffentlicht oder übertragen.

Hosting

Beim Abruf der Website können durch den Hosting-Anbieter technische Zugriffsdaten verarbeitet werden, zum Beispiel zur Sicherheit und Auslieferung der Seite. Bei GitHub Pages beschreibt GitHub eine solche Erfassung in der eigenen Dokumentation.

Keine zentrale Statistik

Die Anwendung nutzt keine Cookies, kein externes Analysewerkzeug, kein Fingerprinting und keine Hall of Fame mit zentral gespeicherten Nutzerprofilen.
